# Changelog

## Unreleased

- Attempts to run on any game or D2RLoader version.
- Crashes are written to the plugin's log.

## 1.0.0 - 2026-10-30

First public release, for Diablo II: Resurrected 3.3 under D2RLoader 1.3.1.

- Hold Left Ctrl and left-click an NPC to skip its dialog menu.
- Vendors trade, Deckard Cain identifies, mercenary NPCs resurrect, and Warriv and Meshif travel.
- Works with every mod and the unmodded game.
- Settings are in `quick-npc.toml`, and the console command is `quick-npc`.
