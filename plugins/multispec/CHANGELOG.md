# Changelog

## 1.0.0 - 2026-10-31

First public release, for Diablo II: Resurrected 3.3 under D2RLoader 1.3.1.

- Each character keeps several skill setups, called specs: 3 by default, up to 99.
- A panel beside the skill tree switches specs in town, with its arrows or the mouse wheel.
- Each spec remembers its left and right mouse skills.
- Save files are never edited; specs are in a file next to the save.
