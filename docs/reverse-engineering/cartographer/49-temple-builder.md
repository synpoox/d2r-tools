## 49. The maze builder's case for LevelType 32 (Act 5 Nihlathak Temples, issue #290)

Build: D2R 3.3 build 93847, image stamp `0x6ab3782c`. Addresses are RVAs of that build. Evidence: **static** (the decompiled builder `0x3e69e0` and picker `0x3eb960`, tables read from the dump bytes at `0x1d0ecb0` and `0x1d0f930`; same method as notes 43, 44), then **in game** (the results are in the PR of issue #290).

| Fact | Evidence | Level |
|---|---|---|
| LevelType 32 (`0x20`) is a case of the builder that calls the ring grower `0x3e9820(level, 2)` and then makes **one** special-room call `0x3eb850(level, 0x1d0f930 + rot * 16, ...)` with `rot = rng % 3`, unless the level id is 124 (the Halls of Vaught preset). It has no walk. For level 123 only, it then makes a second call on row `rot + 3` (the Waypoint variants). A slot level (id above 137) takes the first call only. | decompiled case `0x20` | static |

The hook for special rooms suppresses the call on every slot level (a ring plan sets no entrance), so no Down piece is placed (the SE corner still holds the Up stairs, see the picker row). | table bytes, `SpecialHook` | static |
| The picker's case for LevelType 32 reads the dword at `0x1d0ecb0 + mask * 8` and has no level-id test. Consequence: the row is `{"Temple", 32, "MazeTemple", "Cartographer Temple", 40, 0, {0,0,0,0}, true, 2000, 600, 0, false, 0, {1042, 1044, 1045, 1043}}`, the same fixed-ring path as Harem, Palace Cellar (note 44) and Spider (note 48): `ringPieces` NE, SE, SW, NW, one shape (Shape and Size ignored, with a console and log note), the entrance, event and Boss in three distinct rooms. No new hook.
