## 5. #106 item 8

- **A blank line in `monstats.txt`** (an empty line after the first data row): the game did not start. The loader's compile
  stopped on it and refused to fall back to base data (the same way as a blank line in `superuniques.txt` in #106):

      Excel TXT compilation failed: global/excel/monstats.txt (table=present, rows=752, ...)
      TXT: data/global/excel/monstats.txt; parsed row (includes header): 4; column: 273 (*eol)
      Mod Excel table could not be loaded: data/global/excel/monstats.bin (mod=D2RToolsTest, ...). D2RLoader stopped startup instead of silently falling back to base data.

  So a blank line in `monstats.txt` is not something the plugin can survive; the file was put back after.
- **`.txt` route forced on**: a `signatures.txt` beside `maps.txt` with a `DataTablesBase` row that matches nowhere. The log:

      part DataTablesBase: off: the signature matches nowhere in this game's code
      spawn names: data flag 3, table revision 1: monstats from the game's table OFF, superuniques by the game's name map OFF; the DataTablesBase part is off

  In that game the map Boss still spawned once as a superunique and the Boss event spawned 5 of 5 (1 as a superunique), so the
  `.txt` route works for both. The log has no `spawn '...'` route line in that mode, so the route is shown by the OFF line and
  the results, not by a line naming it. `maps.txt` also warned that Monsters, Boss and Item names are not checked, as expected.
