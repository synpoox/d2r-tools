# Cartographer: Hell check 2 (2026-11-12)

Live in game: origin/main d989586, D2R 3.3 build 93847, D2RLoader 1.3.1-beta, one slot (level 138), test mod and test save,
single player, Hell, Cave Corridor maps, `MazeProbe=1`, `PlayerStats=1`. 8 games. The earlier check is in
[../testing.md](../testing.md). Screenshots and the log are not kept in the repository.

## Passed

- **The Boss is its own `bosses.txt` row**, in 1 of 3 games where its boss room was read correctly (the other two are #183):

      map Boss for 'Warden': 'Test Warden', its own superuniques row
      eventprobe: superunique row 66 at (30980,260): returned 000000015F4B7AC0, once-per-game bit now set
      map Boss 'Test Warden': spawned in the boss room (30960,240) 40 x 40 (as a superunique)

- **The Boss's minions** came with it in that game (superunique spawn).
- **Map monsters** (`Monsters`, `Level`, `Density`, `Uniques`): the listed monsters (rows 19 and 63) were what filled the map, and
  the row and region fields were put back on leaving (`map monsters: level 138 row: 6 field(s) put back`).
- **Player stats** (`PlayerStats=1`, `strength(0)=+40` drawn for 'Events'): shown on the character sheet in the map and gone after
  leaving.

## Failed

- **#183**: the map Boss was refused in 2 of 3 games, as a superunique and then as a plain monster. In both the room was the cell's
  top-left room, a corner of a Cave cell, which is the stale room of #184, not the cell's centre (the game's own spawn search covers
  the whole room, so the exact centre is never the only spot). `cheat goto` to the logged spot snapped back to the entrance:

      eventprobe: superunique row 66 at (30020,140): returned 0000000000000000, once-per-game bit now NOT set
      map Boss 'Test Warden': refused by the game in the boss room (30000,120) 40 x 40 (as a plain monster)

- **#184**: in 5 of 8 games the plan's boss or event room was read as `(1,0) 0 x 0` (4 where it mattered: the map Boss or the event
  never spawned; the 5th rolled no event), and nothing was logged. The walk's record of the room was stale after the build:

      eventprobe: maze boss room (plan room 10) is DRLG room 000000011529D0F0, level 138, rect (1,0) 0 x 0
      eventprobe: the map Boss 'Test Warden' goes in the plan's boss room (1,0) 0 x 0

  Good reads in other games: `maze boss room (plan room 14) ... rect (6000,24) 8 x 8`.
