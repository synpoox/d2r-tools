# Cartographer: Snow check 1 (2026-11-12)

Live in game: the first run of the `Snow` terrain, slot 6, Hell, single player, test save `cartoh`. Game 1 ran the plugin
built from `eaf7701` (PR #198); games 2 and 3 ran `45e28e8` (PRs #205 and #207). The installer added level 140
"Cartographer Snow" (LevelType 31, 192 x 192 at (6000,3600), Layer 84 like level 117) and `OutdoorSnow 140` in
`slots.txt`. The map is 'Frostline' (Snow, Winding, Medium). Games 1 and 2 opened it with AutoCheck and the player walked
into the portal by hand; game 3 opened the Jungle map 'Overgrown' (level 139) with AutoCheck, then tried to open
Frostline. The logs and screenshots are kept outside the repo. The earlier outdoor run is
[outdoor-check-3](2026-11-12-outdoor-check-3.md).

## Findings

- None new. The Snow level and terrain work on the plan-driven outdoor build, and #203 is fixed on `45e28e8`.
- The AutoCheck `stat-changes` step printed FAIL in all 3 games (`map stats ... 4 drawn, no stats`: no monster property
  was drawn). This run did not set up map stats, so it is not a Snow result.

## Not verified

- Opening from the item (the opens were by AutoCheck).
- Wall blocking, and the corners of the map.
- The automap compared with level 117.
- Multiplayer, Normal and Nightmare.
- On-screen banners.
